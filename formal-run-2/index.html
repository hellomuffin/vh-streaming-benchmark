VH-Home benchmark, formal run on the no-self-repair person

VH-Home puts a simulated person in a 3D house to do a chore while an assistant watches and speaks; the engine makes the person commit two mistakes per episode. In the earlier runs the person often repaired its own mistakes, so an episode could be won with no help at all. This run uses the engine in which a mistake stays until the assistant gets the person to fix it. It repeats the same 75 episodes (25 cases, three personas each) for 17 assistants. The plan below is carried out top to bottom by a daemon; a phase is marked done only after the verifier has read every record.
