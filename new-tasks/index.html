Tasks — one goal, a house left wrong

Each task is a single natural goal and the steps come from the state the house is left in. Three classes: A many→many (things piled in one visible place, each goes back to its own room); B everywhere→one (things left where a person would leave them, each named with its room, all go to one place); C things start apart and end apart under one goal such as "tidy the bedroom". The five original benchmark tasks the assistant sweep was scored on follow, filmed through the same engine. Every film opens with an establishing look at each displaced object where it lies. Each film with its instruction was sent to Gemini 3.1 Pro to ask whether they align clause by clause; the verdict is beside each.
