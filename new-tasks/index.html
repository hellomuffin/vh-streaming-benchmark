Redesigned tasks — checked against their own films

Ten routines across all seven apartments, each spanning three rooms and six to nine subgoals, using only actions whose effect is visible on camera. Every named object is reduced to a single copy in the room the instruction names. Each task was filmed completing, and the film plus the instruction were sent to Gemini 3.1 Pro to ask whether they align clause by clause; the verdict is shown beside each.
